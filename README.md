## 🛠️ Installation Guide

1.  Navigate to the subfolder corresponding to your software.
2.  Copy the script files (`.lua`) to your software's Lua directory (usually in %appdata% or the game folder).
3.  Load the scripts via the "Scripts" tab in your in-game menu.
